# Big Boys Junk Removal Replacement Website

This repository is the implementation target for the replacement production website. The client's existing Lovable site is a design and functionality benchmark only. The replacement preserves that approved experience and verified integrations while adding navigation, photography, SEO, service-area discovery, FAQs, and deeper guide content.

Before applying the project, read:

1. `WEBSITE_REPLACEMENT_MASTER_PROMPT.md` for the exact implementation, deployment, and safety boundaries.
2. `REPLACEMENT_IMPLEMENTATION_PLAN.md` for the phased build and replacement process.
3. `PATCH_SUMMARY.md` for the supplied code changes.

Do not deploy through Lovable. Do not upload `.env` or replace the existing production/Supabase environment. Use `.env.example` only to confirm expected variable names.
